# ARCUS Story Specification: ST-010

## Story Metadata
- **Story ID:** ST-010
- **Story Title:** Spatial Map: Route Time-Lapse Replay and Farthest Point Pin
- **Epic:** Spatial Explorations and Visual Mapping
- **App Name:** step-tracker
- **Target Local Environment:** http://localhost:1981
- **Primary Test Target:** Calculation and rendering of home base displacement max distance ("Farthest Point Out") pin, and an interactive time-lapse playback tracer animation on Leaflet maps.

---

## User Story Statement
> **As a** user reviewing my outdoor movement history,  
> **I want** to identify my farthest geographic displacement from home base and replay my walks via an animated route time-lapse player,  
> **So that** I can visualize my peak displacement and relive specific outdoor routes over time.

---

## Context and Business Value
Building upon the static path overlays established in ST-009, this story adds interactive spatial capabilities. By identifying the single farthest coordinate point ever reached from the user's home base (using straight-line Haversine calculations), the app provides a trophy-like spatial achievement. The Route Time-Lapse Replay feature adds an engaging dimension, allowing users to watch a tracer dot animate along recorded GPS coordinates for any selected date at variable speeds.

---

## Scope of Work

1. **Home Base Configuration Engine:**
    - Allow configuration of a "Home Base" coordinate in the Dexie.js `settings` store.
    - Default Home Base coordinate automatically to the earliest recorded GPS sample in `daily_records` if no explicit home coordinate is set by the user.
    - Provide an option on the Spatial Map tab to reset or manually update the Home Base pin location.

2. **Farthest Point Out Calculation Engine:**
    - Iterate through all historical `location_samples` stored across all entries in `daily_records`.
    - Calculate straight-line displacement distance between Home Base coordinate and each GPS sample point using the Haversine formula.
    - Identify the global maximum displacement coordinate point.
    - Render a custom high-visibility marker pin on the Leaflet map at the farthest coordinate location, displaying a permanent popup badge (for example: "Farthest Point Out: 14.8 km from Home Base").

3. **Route Time-Lapse Replay Control Panel:**
    - Integrate a Time-Lapse Control Bar overlay on the Spatial Map view containing:
        - Date Selector dropdown (populated with dates that contain valid `location_samples`).
        - Play / Pause button.
        - Timeline Scrubber slider control (0% to 100% of selected day's walk duration).
        - Playback Speed Selector (1x, 5x, 10x, 20x multiplier speeds).
        - Active Timestamp and Cumulative Distance HUD display.

4. **Tracer Marker Animation Engine:**
    - When playback is triggered for a selected date, clear active map overlays and draw the date's polyline path.
    - Animate a high-contrast tracer dot marker along the polyline path based on recorded epoch timestamps and selected speed multiplier.
    - Smooth marker position transitions between discrete GPS samples using linear interpolation.
    - Update the active timestamp HUD display and distance counter synchronously as the tracer dot moves.

5. **Documentation Updates:**
    - Update repository documentation explaining Home Base selection, Haversine displacement math, Farthest Point calculation, and route playback controls.

## Technical Notes and Schemas

### Settings Store Additions (`Dexie.js`)

| Key | Value Object Structure | Purpose |
| :--- | :--- | :--- |
| `home_base` | `{ lat: 28.6139, lng: 77.2090, set_at: "2026-08-08T10:00:00.000Z" }` | Stores home base anchor coordinate |
| `farthest_point_cache` | `{ lat: 28.7041, lng: 77.1025, distance_km: 14.8, date: "2026-05-12" }` | Cached global max displacement record |

### Haversine Distance Formula
Given Home Base `(lat1, lon1)` and Sample Point `(lat2, lon2)`:
- `a = sin²(Δlat/2) + cos(lat1) * cos(lat2) * sin²(Δlon/2)`
- `c = 2 * atan2(√a, √(1−a))`
- `d = R * c` (where `R = 6371 km`)

## Acceptance Criteria (Definition of Done)

### Scenario 1: Farthest Point Out Pin Calculation
- **Given** historical GPS records across multiple months,
- **When** the Spatial Map tab loads,
- **Then** the application evaluates all GPS sample points against the Home Base coordinate,
- **And** pins the maximum displacement coordinate with a badge displaying "Farthest Point Out: X.X km from Home Base".

### Scenario 2: Executing Route Time-Lapse Playback
- **Given** a selected date containing 500 GPS location points spanning a 2-hour walk,
- **When** the user selects the date and clicks "Play" at 10x speed,
- **Then** a tracer dot animates along the polyline path completing in 12 seconds,
- **And** the active timestamp and accumulated distance HUD updates smoothly in real time.

### Scenario 3: Timeline Scrubber Interaction
- **Given** an active route time-lapse session,
- **When** the user manually drags the timeline scrubber to the 50% position,
- **Then** the tracer dot jumps immediately to the exact midpoint coordinate of that day's route,
- **And** the active timestamp HUD reflects the timestamp corresponding to that midpoint coordinate.

### Scenario 4: Technical Documentation Update
- **Given** completion of the route time-lapse and farthest pin modules,
- **When** reviewing repository documentation,
- **Then** Home Base rules, Haversine displacement logic, and time-lapse playback architecture are accurately documented.
