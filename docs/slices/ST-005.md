# ARCUS Story Specification: ST-005

## Story Metadata
- **Story ID:** ST-005
- **Story Title:** Monthly Calendar Heatmap Grid and Day Detail Drawer
- **Epic:** Data Visualization and Historical Review
- **App Name:** step-tracker
- **Target Local Environment:** http://localhost:1981
- **Primary Test Target:** Interactive monthly grid calendar rendering, target-based color classification, monthly aggregate metric calculation, and side-drawer detail view.

---

## User Story Statement
> **As a** user reviewing my fitness habits,  
> **I want** to see a monthly calendar view color-coded by target achievement with an interactive daily detail view,  
> **So that** I can spot monthly consistency patterns, evaluate aggregate monthly totals, and inspect specific daily records.

---

## Context and Business Value
While daily streak numbers provide immediate momentum, monthly calendar heatmaps provide macro-level visibility into habit consistency. This story implements the Calendar tab interface, displaying a 7-column calendar grid for any selected month and year, computing monthly summary aggregates, color-coding daily tiles based on performance thresholds, and providing a slide-out drawer to inspect granular daily metrics.

---

## Scope of Work

1. **Monthly Calendar Navigation and Grid Layout:**
   - Render a 7-column grid layout (Monday through Sunday) on the Calendar tab.
   - Provide month and year navigation controls (Previous Month, Next Month, and Direct Month/Year Dropdown selectors).
   - Display day-of-week headers and correctly offset initial day padding for the selected month.

2. **Performance Color Classification Engine:**
   - For each day in the selected month, compare `effective_distance_km` against the active goal commitment for that date.
   - Assign visual classification states:
     - State 0 (No Data / Future Date): Neutral background style.
     - State 1 (Missed Target): Below active daily goal target.
     - State 2 (Met Target): 100% to 199% of active daily goal target.
     - State 3 (Exceeded Target): 200%+ of active daily goal target.
   - For days where `is_overridden == true`, display a persistent visual override indicator (asterisk symbol or badge) on the calendar tile.

3. **Monthly Aggregate Summary Header:**
   - Calculate and display aggregate summary metrics for the currently selected month:
     - Total Monthly Steps
     - Total Monthly Distance (km)
     - Average Daily Steps (Total Monthly Steps / Days Elapsed in Month)
     - Monthly Commitment Target Hit Rate Percentage (`(Days Target Met / Total Days) * 100`)

4. **Day Detail Drawer Component:**
   - Enable click/tap selection on any valid calendar date tile.
   - Slide open a Day Detail Drawer from the side or bottom containing:
     - Selected Date Header (e.g., "August 8, 2026").
     - Effective Steps and Effective Distance (km).
     - Synced Steps vs. Verified Manual Steps comparative metrics.
     - Override status indicator and override note (if present).
     - Action button to trigger edit/override form (form behavior defined in `ST-006`).

5. **Documentation Updates:**
   - Update repository documentation explaining calendar color classification logic, monthly aggregate formulas, and drawer interactions.

## Technical Notes and Schemas

### Tile Color Classification Matrix

| Performance Ratio | Category Name | Classification Rule |
| :--- | :--- | :--- |
| `ratio < 1.0` | Missed Target | `effective_distance_km < target_distance_km` |
| `1.0 <= ratio < 2.0` | Met Target | `effective_distance_km >= target_distance_km` |
| `ratio >= 2.0` | Exceeded Target | `effective_distance_km >= (target_distance_km * 2)` |
| `is_overridden == true` | Manual Override | Visual indicator appended to tile |

### Monthly Aggregate Formulas
- **Days Evaluated:** Days elapsed in month (or total days in month for past months).
- **Average Daily Steps:** `Math.round(total_monthly_steps / days_evaluated)`
- **Monthly Hit Rate:** `Math.round((target_met_days / days_evaluated) * 100)`

## Acceptance Criteria (Definition of Done)

### Scenario 1: Monthly Calendar Grid Generation
- **Given** the user navigates to the Calendar tab on `http://localhost:1981`,
- **When** selecting August 2026,
- **Then** a 7-column grid renders representing August 2026 with correct day alignment and date labels.

### Scenario 2: Color Classification and Override Badge Display
- **Given** historical data for a month where Day 1 missed target, Day 2 met target, Day 3 doubled target, and Day 4 contains a manual override,
- **When** viewing the monthly calendar,
- **Then** Day 1 renders with Missed styling, Day 2 with Met styling, Day 3 with Exceeded styling,
- **And** Day 4 displays an override indicator symbol on the tile.

### Scenario 3: Month Navigation and Aggregate Summary Update
- **When** the user changes the selected month from August 2026 to July 2026,
- **Then** the grid updates immediately to display July 2026,
- **And** the monthly aggregate header updates to show July's total steps, total distance, average steps, and hit rate percentage.

### Scenario 4: Opening Day Detail Drawer
- **Given** a populated calendar grid,
- **When** the user clicks on a specific date tile,
- **Then** the Day Detail Drawer slides open displaying the selected date's effective steps, effective distance, original synced values, and override note if present.

### Scenario 5: Technical Documentation Update
- **Given** completion of the calendar grid and drawer components,
- **When** reviewing repository documentation,
- **Then** calendar color rules, drawer specs, and aggregate metrics are accurately documented.
