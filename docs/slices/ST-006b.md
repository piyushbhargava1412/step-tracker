# ARCUS Story Specification: ST-006b

## Story Metadata
- **Story ID:** ST-006b
- **Story Title:** Group Challenge Tracker Widget and Clipboard Exporter
- **Epic:** Goal Tracking and Community Engagement
- **App Name:** step-tracker
- **Target Local Environment:** http://localhost:1981
- **Primary Test Target:** Dashboard Challenge Tracker widget UI, calculation of active/completed challenge step metrics, Dexie.js challenge persistence, and one-click formatted text generation for chat sharing.

---

## User Story Statement
> **As a** participant in fitness group step challenges,  
> **I want** a dedicated Challenge Tracker widget on my Dashboard that calculates my daily and cumulative challenge steps,  
> **So that** I can track my progress across custom timeframes and instantly export formatted updates to my group chat.

---

## Context and Business Value
Fitness challenges on community channels (such as WhatsApp, Telegram, or Discord) require participants to regularly post daily step counts along with cumulative totals logged from the start of the challenge. Manually calculating sums across dates in standard calendar views is tedious and error-prone. This story introduces a persistent Dashboard widget that automatically calculates yesterday's step count, cumulative step volume within defined challenge dates, average daily pace, and generates formatted text for one-click clipboard copying.

---

## Scope of Work

1. **Dashboard Widget UI Integration:**
   - Integrate a "Group Challenge Tracker" card into the right column of the Dashboard view, positioned alongside the Active Streaks component.
   - Design a compact configuration header containing:
     - Start Date Picker (defaults to 1st day of current month if unset).
     - End Date Picker (defaults to last day of current month if unset).
     - Save / Edit toggle to switch between configuration inputs and active metric view.

2. **Metrics Computation Engine:**
   - **Yesterday's Steps:** Query `daily_records` for `effective_steps` on `Today - 1 Day`.
   - **Cumulative Total Steps:** 
     - *Active Challenge (`StartDate <= Today <= EndDate`):* Sum `effective_steps` for all dates from `StartDate` up to `Today - 1 Day`.
     - *Completed Challenge (`EndDate < Today`):* Sum `effective_steps` for all dates from `StartDate` through `EndDate`.
   - **Active Day Counter:** Calculate elapsed days (`(Today - 1 Day) - StartDate + 1`) or total challenge duration if finished.
   - **Average Daily Pace:** Compute `Cumulative Total Steps / Elapsed Days`.

3. **Challenge Persistence in Dexie.js:**
   - Save active challenge date bounds and optional challenge name in the `settings` object store under key `active_challenge`.
   - Automatically load saved challenge settings on app startup so users do not need to re-enter challenge dates upon refreshing or reopening the application.

4. **One-Click Group Chat Clipboard Exporter:**
   - Add a `📋 Copy Group Update` action button on the widget card.
   - On click, format the current challenge metrics into a standardized plain-text string and write it directly to the system clipboard using `navigator.clipboard.writeText()`.
   - Display a temporary visual feedback badge (e.g., "Copied to Clipboard!") for 2 seconds following successful execution.

5. **Documentation Updates:**
   - Update repository documentation explaining the Challenge Tracker widget, date boundary calculations, settings schema structure, and clipboard sharing mechanics.

## Technical Notes and Schemas

### Settings Store Schema Addition (`settings`)

```json
{
  "key": "active_challenge",
  "value": {
    "name": "Step Challenge",
    "start_date": "2026-08-01",
    "end_date": "2026-08-31",
    "created_at": "2026-08-01T00:00:00.000Z"
  }
}

```

### Formatted Clipboard Text Output Standard

```text
🚶 Step Challenge Update
📅 Yesterday's Steps: 9,420
📊 Cumulative Total: 84,500 steps (Day 11)
📈 Average Pace: 7,681 steps/day

```

## Explicit Out of Scope

* Automated direct API messaging integrations with WhatsApp, Telegram, or Discord.
* Multi-user leaderboards or social server syncing (keeps step-tracker serverless and private).
* Multiple simultaneous active challenge presets (Phase 1 supports 1 active challenge timeframe).

## Acceptance Criteria (Definition of Done)

### Scenario 1: Active Challenge Metrics Calculation

* **Given** an active challenge configured from August 1 to August 31 with historical step data,
* **When** viewing the Dashboard Challenge Tracker widget on August 12,
* **Then** the widget displays `effective_steps` for August 11 as "Yesterday's Steps",
* **And** displays the sum of `effective_steps` from August 1 through August 11 as "Cumulative Total Steps",
* **And** displays elapsed duration as "Day 11 of 31".

### Scenario 2: Completed Challenge Handling

* **Given** a challenge configured with an End Date in the past (e.g., July 1 to July 31),
* **When** viewing the widget on August 12,
* **Then** the widget displays a "Challenge Finished" badge,
* **And** displays the total locked step count summed across all 31 days of July.

### Scenario 3: One-Click Clipboard Copying

* **Given** an active challenge widget with populated step metrics,
* **When** the user clicks `📋 Copy Group Update`,
* **Then** the formatted update string is written to the system clipboard,
* **And** a "Copied to Clipboard!" notification badge appears briefly on the card.

### Scenario 4: Challenge Persistence Across Sessions

* **Given** a user who sets a challenge start date of August 1 and end date of August 31,
* **When** the browser tab is refreshed or reopened,
* **Then** the saved challenge dates load automatically from the Dexie.js `settings` store without prompting re-entry.

### Scenario 5: Technical Documentation Update

* **Given** completion of the Group Challenge Tracker module,
* **When** reviewing repository documentation,
* **Then** challenge calculation boundaries, settings schema, and clipboard export rules are accurately documented.
