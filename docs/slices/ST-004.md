# ARCUS Story Specification: ST-004

## Story Metadata
- **Story ID:** ST-004
- **Story Title:** Effective Lock Streak and Goal-Tier Streaks Engine
- **Epic:** Streak Evaluation and Analytics
- **App Name:** step-tracker
- **Target Local Environment:** http://localhost:1981
- **Primary Test Target:** Calculation and rendering of the Unified Active Streak using the Effective Date Lock rule, Goal-Tier Streaks, and lifetime achievement metrics.

---

## User Story Statement
> **As a** user striving for daily walking discipline,  
> **I want** my active streak evaluated against the goal target effective on each specific historical date,  
> **So that** increasing my daily goal target today does not retroactively break my previously earned historical streak.

---

## Context and Business Value
Traditional streak engines retroactively apply new goals across historical data, which can break a long active streak and demotivate users. This story implements the Effective Date Lock streak calculation algorithm. It evaluates each historical day against whatever daily commitment goal was active on that specific date. Additionally, it tracks independent Goal-Tier Streaks (>1 km, >3 km, >5 km, >10 km) and calculates lifetime 10k+ step achievement rates to reward long-term discipline.

---

## Scope of Work

1. **Unified Active Streak Calculation Engine:**
   - Implement an evaluation algorithm that traverses historical records backwards from current/yesterday date in Dexie.js `daily_records`.
   - Evaluate each date against the target goal stored for that date in `settings` (or historical target logs).
   - If today's goal is already met, include today in the streak count; if today's goal is in-progress, evaluate from yesterday backwards without breaking the active streak.
   - Increment streak counter for consecutive passing days; terminate calculation at the first non-passing day.

2. **Goal-Tier Streaks Engine:**
   - Calculate active continuous streaks for standardized distance thresholds:
     - Tier 1: > 1.0 km daily
     - Tier 2: > 3.0 km daily
     - Tier 3: > 5.0 km daily
     - Tier 4: > 10.0 km daily
   - Calculate historical maximum (best ever) streak length for each tier.

3. **Hall of Fame (Top 3 Streaks):**
   - Traverse full historical database to identify and rank the Top 3 longest unbroken unified streak periods in user history.
   - Store start date, end date, and total day length for top 3 records.

4. **Secondary Achievement Metrics:**
   - Calculate lifetime total days with step count >= 10,000.
   - Calculate lifetime 10k consistency percentage (`(total_10k_days / total_days_in_db) * 100`).

5. **Dashboard Header UI Rendering:**
   - Update Dashboard header banner to display:
     - Unified Active Streak count with active goal label and effective date lock statement.
     - Lifetime 10k+ step days count and consistency percentage.
   - Render Goal-Tier Streak mini-cards displaying active streak count per tier.

6. **Documentation Updates:**
   - Update user and technical documentation explaining Effective Date Lock rules, Goal-Tier calculation logic, and streak edge case handling.

## Technical Notes and Schemas

### Effective Date Lock Rule Logic
For each day `D` moving backwards from today:
1. Determine active goal `G(D)` effective on date `D`.
2. Retrieve `effective_steps` and `effective_distance_km` for date `D`.
3. If `effective_distance_km >= G(D)`, increment active streak by 1 and continue to `D - 1`.
4. If `effective_distance_km < G(D)` AND `D` is today (in-progress), skip `D` and continue evaluation from `D - 1`.
5. If `effective_distance_km < G(D)` AND `D` is in the past, terminate loop and return accumulated count as active streak.

### Goal-Tier Matrix

| Tier Name | Threshold | Evaluation Rule |
| :--- | :--- | :--- |
| Tier 1km | >= 1.0 km | Consecutive daily records meeting >= 1.0 km |
| Tier 3km | >= 3.0 km | Consecutive daily records meeting >= 3.0 km |
| Tier 5km | >= 5.0 km | Consecutive daily records meeting >= 5.0 km |
| Tier 10km | >= 10.0 km | Consecutive daily records meeting >= 10.0 km |

## Acceptance Criteria (Definition of Done)

### Scenario 1: Unified Streak Calculation with Goal Changes
- **Given** a user had a 30-day streak under a 3.0 km goal target,
- **When** the user updates their daily goal target to 5.0 km starting today,
- **Then** the historical 30 days remain evaluated against 3.0 km,
- **And** the Unified Active Streak displays 30 days without resetting to 0.

### Scenario 2: Handling Today's In-Progress Status
- **Given** a user has an active 10-day streak up to yesterday,
- **When** viewing the Dashboard today before completing today's goal target,
- **Then** the Unified Active Streak displays 10 days (does not show broken streak),
- **And** completing today's target increments the active streak to 11 days immediately.

### Scenario 3: Goal-Tier Streaks Display
- **Given** historical data containing varying daily distances,
- **When** the Dashboard loads,
- **Then** mini-cards render independent continuous streaks for >1km, >3km, >5km, and >10km tiers.

### Scenario 4: Lifetime 10k+ Step Counter
- **Given** a database containing 100 total days where 40 days have >= 10,000 steps,
- **When** viewing the Dashboard secondary banner,
- **Then** the metric displays "40 / 100 Days (40.0% Lifetime)".

### Scenario 5: Documentation Update
- **Given** completion of the streak engine,
- **When** reviewing repository documentation,
- **Then** Effective Date Lock rules and Goal-Tier evaluation logic are accurately documented.
