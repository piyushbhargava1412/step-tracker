# ARCUS Story Specification: ST-003

## Story Metadata
- **Story ID:** ST-003
- **Story Title:** Today's Live Progress and Goal Commitment UI
- **Epic:** Goal Tracking and Progress Monitoring
- **App Name:** step-tracker
- **Target Local Environment:** http://localhost:1981
- **Primary Test Target:** Dynamic rendering of today's step/distance progress card against user-configurable daily commitment targets.

---

## User Story Statement
> **As a** health-conscious user,  
> **I want** to set a daily distance commitment goal and see today's live completion status,  
> **So that** I know exactly how many steps or meters remain to fulfill my daily commitment.

---

## Context and Business Value
A core driver of fitness habit retention is immediate visibility into today's remaining effort. This story introduces the Goal Commitment configuration engine and renders "Today's Progress Card" prominently on the Dashboard tab. It reads today's synced step counts from local storage, evaluates them against the active daily target, and provides visual progress feedback.

---

## Scope of Work

1. **Goal Commitment Configuration Engine:**
    - Provide a goal target selector on the Dashboard allowing standard preset selections (1 km, 3 km, 5 km, 10 km) or custom distance inputs.
    - Store the active goal commitment setting in the Dexie.js `settings` store with fields for `target_distance_km`, `target_steps` (derived at standard 1 km = 1,312 steps), and `effective_from_date` ISO string.
    - Default initial goal setting to 3.0 km (~3,936 steps) if no custom target has been configured.

2. **Today's Data Resolution:**
    - Resolve current system date in `YYYY-MM-DD` local time format.
    - Query Dexie.js `daily_records` store for today's record.
    - If today's record exists, use `effective_steps` and `effective_distance_km`.
    - If no record exists for today yet, default current progress metrics to 0 steps / 0.0 km.

3. **Today's Progress Card UI Component:**
    - Render a high-visibility progress card on the Dashboard tab displaying:
        - Today's completed steps and completed distance (km).
        - Target distance (km) and target steps.
        - Percentage completion metric (`(completed / target) * 100`).
        - Dynamic remaining metric (remaining steps and remaining distance in meters or kilometers).
    - Render a visual HTML5 progress bar element representing percentage completion.

4. **Goal Achievement Visual Feedback:**
    - State A (In-Progress, < 100%): Display remaining steps/distance counter and active progress bar.
    - State B (Goal Met, >= 100%): Display completion badge, progress bar at 100% width, and celebration status message ("Daily Commitment Met").

5. **Documentation Updates:**
    - Update repository user guide explaining goal setting configuration, conversion formulas, and progress card behavior.

## Technical Notes and Schemas

### Settings Store Data Schema (`Dexie.js`)

| Key | Value Object Structure | Purpose |
| :--- | :--- | :--- |
| `active_goal` | `{ target_distance_km: 5.0, target_steps: 6560, effective_from: "2026-08-08" }` | Stores active daily commitment target |

### Calculation Formulas
- **Target Steps:** `target_distance_km * 1312.33` (rounded to nearest integer)
- **Completion Percentage:** `Math.min(100, Math.round((effective_steps / target_steps) * 100))`
- **Remaining Steps:** `Math.max(0, target_steps - effective_steps)`
- **Remaining Distance (Meters/KM):**
    - If `remaining_km < 1.0`: `Math.round(remaining_km * 1000)` + `" meters"`
    - If `remaining_km >= 1.0`: `remaining_km.toFixed(2)` + `" km"`

## Acceptance Criteria (Definition of Done)

### Scenario 1: Default Goal Target Initialization
- **Given** a new user launching the application with no saved settings,
- **When** the Dashboard tab loads,
- **Then** the active daily commitment goal defaults to 3.0 km (~3,936 steps),
- **And** the setting is saved in Dexie.js `settings` store under key `active_goal`.

### Scenario 2: Updating Daily Commitment Target
- **Given** the user selects a new goal commitment target of 5.0 km,
- **When** the user confirms the target update,
- **Then** Dexie.js `settings` updates the `active_goal` record,
- **And** Today's Progress Card immediately recalculates percentage completion and remaining distance against 5.0 km.

### Scenario 3: Rendering In-Progress State (< 100%)
- **Given** today's effective step count is 3,200 steps and active goal is 5,000 steps (~3.8 km),
- **When** viewing Today's Progress Card,
- **Then** completion percentage renders as 64%,
- **And** remaining metric displays "1,800 steps remaining (~1.37 km)".

### Scenario 4: Rendering Goal Met State (>= 100%)
- **Given** today's effective step count is 6,800 steps and active goal is 5,000 steps,
- **When** viewing Today's Progress Card,
- **Then** progress bar renders at 100% capacity,
- **And** remaining metric displays "Daily Commitment Met",
- **And** goal completion visual indicator is active.

### Scenario 5: Technical Documentation Update
- **Given** completion of Today's Progress Card implementation,
- **When** reviewing repository documentation,
- **Then** goal configuration usage and metric calculation rules are accurately documented.
